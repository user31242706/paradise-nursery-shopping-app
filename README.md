# Paradise Nursery Shopping Application

Paradise Nursery is an e-commerce web application built using React and Redux. It allows users to browse various categories of houseplants, add them to a shopping cart, update item quantities, and view the total costs dynamically.

## Features
- Landing page with About Us and Get Started button
- Product listing with categories, thumbnails, and descriptions
- Dynamic shopping cart powered by Redux Slice
- Quantity increment, decrement, and item removal
